# Localization Guide

Keep the operating-chain framework stable. Localize terminology, examples, and tone.

## Default Rules

- Respond in the user's language.
- If the market is known, use local system categories and operating examples.
- If the market is unknown, infer lightly from language but avoid naming vendors.
- Do not invent vendor features, prices, availability, or local support.
- Do not name specific vendor, platform, or software brands in guided questions, choices, or default examples. Mention brands only when the user provided them or explicitly asks to compare/research named vendors.

## China

Use owner-facing Chinese. Common terms:

- 收银系统
- 小程序
- 外卖平台
- 线上点餐系统
- 即时通讯/协同工具
- 供应链系统
- 财务软件
- 储值、券、会员、私域
- 门店微信群

Tone:
- plain,
- concrete,
- avoid consulting jargon,
- emphasize real exception scenarios.

## English / International

Common terms:

- POS
- online ordering
- delivery platforms
- inventory system
- accounting
- labor scheduling
- loyalty / CRM
- KDS
- reporting dashboard

## Southeast Asia

Use local channel examples only when the user names the market or asks for vendors. Common categories:

- POS
- delivery platforms
- messaging or collaboration channels,
- inventory,
- central kitchen,
- accounting.

## Europe

Mention privacy and compliance only when relevant. Common categories:

- POS,
- delivery aggregators,
- accounting integration,
- payment compliance,
- labor scheduling,
- reporting.
