# Operating-Chain Framework

Use this framework for every market. Localize words and examples, but keep the chain.

## Core Dimensions

1. **Store Execution**: whether front-line tasks happen consistently without the owner personally pushing them.
2. **Order and Channel Flow**: whether dine-in, takeout, delivery, and online ordering enter operations cleanly.
3. **Supply and Inventory Loop**: whether ordering, receiving, transfer, count, waste, and recipe/costing data connect.
4. **Finance and Reconciliation**: whether sales, payment, inventory, waste, procurement, and accounting numbers can be explained.
5. **Customer and Loyalty Operations**: whether membership, stored value, coupons, CRM, and re-engagement are connected to real store execution.
6. **System Fit and Data Handoff**: whether POS, delivery, inventory, accounting, labor, loyalty, and reporting systems exchange the right data.
7. **Responsibility and Organization**: whether every critical action has an owner, reviewer, correction path, and audit trail.

## Four Root-Cause Buckets

- **System**: missing capability, poor configuration, weak integration, or unsuitable tool.
- **Workflow**: the real operating path is unclear, too complex, or not followed.
- **Data handoff**: data exists but cannot move cleanly between roles, systems, or reports.
- **Responsibility**: nobody owns creation, review, correction, or final explanation.

## Default Diagnostic Question

For any problem, ask:

> If the system changed tomorrow, would the same problem still happen because the workflow, data handoff, or responsibility boundary is unclear?

If yes, do not frame the problem as purely a system problem.
