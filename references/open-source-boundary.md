# Open Source Boundary

Everything in this repository is visible after publishing. Keep the open skill useful without exposing the full commercial product.

## Safe to Open Source

- diagnostic dimensions,
- questionnaire structure,
- baseline scoring logic,
- common failure patterns,
- vendor question templates,
- 30-day action plan templates,
- bilingual usage guidance,
- synthetic examples.

## Use Carefully

- high-quality industry insight,
- highly recognizable report language,
- complex scoring weights,
- details distilled from real interviews or customer conversations.

## Do Not Include

- real customer data,
- deals, refunds, channel, or finance records,
- payment code or configuration,
- API keys or environment variables,
- private model prompts,
- complete commercial PDF report templates,
- real vendor ratings or rankings.
