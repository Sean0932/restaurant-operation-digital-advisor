# Example: Follow-Up Review

Use inside the 30-Day Action Plan mode when the user returns after taking action.

User:

> One month ago you suggested we check 10 SKUs and split reconciliation differences. We did the SKU check and organized delivery cancellation issues, but month-end reconciliation is still slow.

Expected handling:

- Do not restart the full readiness check.
- Ask only what changed, what improved, and what is still stuck if the user did not provide enough detail.
- Decide the next phase.

Output points:

- Progress: moved from vague problem to concrete exception samples.
- Root cause may shift from general workflow confusion to finance definitions or data handoff.
- Next phase: use real samples to test current systems and vendors; clarify owner and correction path for the highest-frequency mismatch.
