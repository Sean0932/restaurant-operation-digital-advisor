# Example: Expansion Readiness

Use this when the user is opening more stores or regions.

Check:

- Which tasks still depend on the owner?
- Which tasks depend on a strong store manager?
- Which numbers cannot be explained by headquarters?
- Which exceptions lack a standard correction path?
- Which systems vary by store?

Output:

- expansion readiness judgment,
- strongest scaling risk,
- three gate checks before opening more stores,
- 30-day cleanup plan.
