# Example: US Single Store

User:

> I run one restaurant. We use a POS, DoorDash/Uber Eats, spreadsheets for inventory, and QuickBooks. Sales and inventory never line up. Should I replace my POS?

Expected handling:

- Use Issue Diagnosis + Integration & Data Handoff.
- Respond in English with US-market terminology.
- Do not recommend specific vendors unless current sources are available or the user provides options.

Output points:

- Do not assume POS replacement is the first move.
- Check order, refund, delivery cancellation, inventory deduction, and accounting handoff.
- Build a vendor demo scenario from real mismatches.
